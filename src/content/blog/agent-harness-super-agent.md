## 开场：一个小场景

假设你对 AI 说：“帮我订一趟全家旅行，两大一小，下个月十号出发，五天，预算一万五。”

第一种 AI 回你：“好的！祝您旅途愉快，记得带好证件哦。”

第二种 AI 回你：“机票已订，三人往返，共 6820 元；酒店比了三家，选了离地铁近、有儿童床的那家，四晚 3960 元；行程按‘上午玩、下午休息’排好了，孩子午睡时间留出来了。总花费 10780 元，还剩 4220 元机动。要不要我把行程发你手机上？”

差别在哪？第一种会说，第二种会做。

会说，是它读懂了你的话，然后接着往下说。会做，是它读懂了你的话，然后真的去打开网页、打开文件、去查、去比价、去下单、去核对。

就这一字之差，后来衍生出一堆让人犯晕的词：Agent、Harness、Super Agent。三个词各指一样东西，回答的其实是三个问题——谁在干活、谁给它配装备、谁替你统筹。这篇文章不从“它们由什么零件拼成”来讲，只讲各自负责什么，这样最容易分清。

下面一个一个说。

## 一、Agent：不是会聊天的，是会动手的

先说 Agent。这个词现在被翻译成“智能体”，听着玄乎，其实你可以把它想成一个你请来帮忙办事的帮工。

不过先说清楚一件事：这个“帮工”不是单个零件，而是两样东西合起来的——一个会思考的脑子（也就是大模型），加上一套让他能连着干活的运行机制。两样凑齐，才算一个 Agent。后面为了方便，我就干脆把他当成一个人来说。

帮工要真能把事办成，身上得有四样东西。

**第一样，耳朵——他得听清你要什么。**

你说“下个月十号”，他不能听成“这个月十号”；你说“两大一小”，他得知道小孩要儿童床。在 AI 的世界里，这一步叫上下文（Context），说白了就是“它此刻能看见、能记住的那些话”。上下文给得含糊，帮工再能干也白搭——你只说“订个酒店”，他给你订到一家离市区两小时车程的，这怪谁？

顺便记住一点：这里说的上下文，指的是它看见的那些话，是“内容”本身；至于这些话该怎么排、按什么顺序给它，第二节还会专门讲。

**第二样，脑子——他得会想步骤。**

订旅行不是一件事，是十几件事：查航班、比价格、看酒店位置、算总预算、排每天行程。帮工得自己把大任务拆成小步骤，还得知道先做哪步。这个“脑子”，就是大语言模型（LLM），也就是我们平时说的那个“很会说话的 AI”。它擅长理解和推理，但它本身只会输出文字，不会真的去买票。

**第三样，手——他得能真的去做。**

光会想“我应该去查一下航班”，没用。他得真的打开网站、输入日期、看到价格。这一步叫工具调用（Tool Calling）：AI 不再只是说话，而是能伸手去按按钮——查天气、搜网页、算数、发邮件、读文件。有没有这双手，是“会说”和“会做”的分水岭。 这里说的“手”，指的是它知道该用哪个工具；至于工具从哪来、谁把它接到手上并真的执行，下一节再讲。

**第四样，小本子——他得记住做到哪了。**

办到第五步，他不能忘了第一步的结论。这个本子叫记忆（Memory）。没有它，帮工每做一步都像失忆重来，你交代十遍他问十遍。

四样凑齐，帮工就开始干活了：听 → 想 → 做 → 记 → 看结果 → 再想下一步。这个“转圈”的过程，行业里叫 Agent Loop，也就是主循环。你可以理解成他一边干一边回头看：“成了吗？没成，换个办法。”

![图1：Agent 的四样东西](/images/blog/agent-harness-super-agent/fig1-agent-four-parts.webp)

这就是 Agent 和聊天机器人的真正区别。聊天机器人是问一句答一句，你问“怎么订票”，它告诉你流程，然后就停了，等你再问。Agent 是你给个目标，它自己想办法——中间遇到“这个航班卖完了”，它不会回来问你“那怎么办呀”，而是自己去找下一班。

不过这里得给你泼盆冷水：现在大部分 AI 还处在“刚学会动手”的阶段。 简单任务能干得挺漂亮，步骤一多、情况一变，就容易犯迷糊、绕圈子、甚至自信地把事办错。所以碰上“全自动 AI 员工”“一句话搞定一切”的宣传，先别慌，也别全信。

## 二、Harness：帮工身上的那套装备

现在问题来了：一个帮工光有脑子、也肯干活，为什么还是常常办不成事？

因为他没工具、没规矩、没安全绳。你让他去查航班，他连浏览器都没有；你让他去比价，他连网都上不了；你让他下单，他分不清哪一笔钱该自己刷、哪一笔得先问你一声。

所以光有 Agent 不够，还得给它配一整套装备。这套装备，就叫 Harness——原意是“马具、挽具”，就是套在马身上、让马的力气能真正使到车上的那套东西。翻成大白话：工具包 + 工作手册 + 记事本 + 检查清单 + 安全绳。

先说一句总纲：第一节讲的是他得有什么本事，这一节讲的是这些本事具体靠什么落地。所以下面这几件装备，几乎都能和前面某一样东西对上——工具包对应那只“手”，工作手册对应“想好之后一步步怎么做”，记事本对应“小本子”；而检查清单和安全绳是前四样里没提过的，属于额外加上的保险。

![图2：本事与装备](/images/blog/agent-harness-super-agent/fig2-skills-vs-gear.webp)

顺带说一句，你可能听过另一种说法：agent ＝ 模型 ＋ harness。那是另一种切法——把帮工和装备合成一个整体看，说的是“由什么拼成”，不是“谁负责什么”。两种说法不冲突，只是这把尺子量的是零件，本文量的是分工。

具体是这几件：

**工具包——能打开网页、能读文件、能算数、能发邮件。**

这里要分清两件事，因为“会用”和“真有”完全是两回事。

前面说 Agent“会做”，说的是它知道该用哪个工具——它会在心里说一句“现在该查航班了”。请注意，这句话说出来，仍然只是一句话：它没有浏览器，没有你的订票账号，也没有替你按下付款的权限。

就像一个人会说“我这就给航空公司打个电话”。他清楚该打给谁、该说什么，这是本事。可桌上要是根本没有那部电话、线路也没接上，这个电话就永远打不出去。

工具包就是那部电话、那条线路：它把“该查航班了”这个念头，真的变成一次查询，再把价格送回到它眼前。

这一层的分工可以一句话说清：模型负责出主意，装备负责让主意一步步落地。

顺带提一句：这些工具怎么接进来，现在也慢慢有了通用标准，比如常听到的 MCP。它的好处像插座统一规格——工具按这个规格做一次，很多不同的 AI 都能直接用，不必每换一个就重接一遍。

<strong>工作手册——先做什么、后做什么、做到什么程度算完。</strong>这份手册写得好不好，直接决定他是“有条不紊”还是“东一榔头西一棒子”。

这里有两个容易混的词，顺一下：前面第一节说的上下文（Context），是他此刻能看见的那些话，是一件具体的东西；而这份手册背后是另一件事——上下文工程（Context Engineering），说的是怎么决定让他看见什么、按什么顺序看、看多少。前者是“给他看的东西”，后者是“怎么给”的手艺。核心不是给 AI 更多的话，而是给它正好的话——该知道的都知道，不该占地方的别占。

<strong>记事本——不会做完就忘。</strong>长任务里，记忆怎么存、存什么、什么时候翻出来看，都是学问。

这里可能有人会问：这不是第一节那只“小本子”吗？其实是两件事。第一节讲的是他必须有记性——这是能力；这里讲的是这份记性怎么落到实处——记在哪儿（临时塞进对话里，还是写进一个长期保存的地方）、记多细、什么时候翻出来看、看多少、旧的怎么清掉。

说白了：前者是“得记得住”，后者是“拿什么记、怎么记”。同样一个帮工，本子用得糙，做到第八步就忘了第三步；用得细，几十步也不乱。

<strong>检查清单——做错了自己返工。</strong>帮工交活之前先自查一遍：“日期对吗？人数对吗？钱够吗？”这一步看着笨，却是靠谱和不靠谱的分界线。

<strong>安全绳——大事要先问你。</strong>查资料可以自己来，花钱必须你点头。技术上，前一半叫沙箱（Sandbox）：给帮工划一个圈，圈里随便折腾；后一半靠人工确认：踩到线的事，必须停下来等你一句“可以”。没有安全绳的 Agent，不是能干，是危险。

这里有个特别容易被忽略的点：同一个帮工，装备好坏，差别巨大。

同样一个模型，接上搜索、接上计算器、接上检查清单、接上“花钱要确认”，它就能把一趟旅行从头办到尾；把这些全撤掉，它立刻退化成一个只会说“祝您旅途愉快”的聊天框。

所以现在真正在比拼的，往往不是“谁的 AI 更聪明”，而是谁的这套装备做得更细、更稳、更不容易出事。

## 三、Super Agent：不是一个帮工，是一支管家团队

到这一步，你已经有个装备齐全、能自己办事的帮工了。那 Super Agent 又是什么？

先说一句：这个词眼下还没有统一定义，各家说法不太一样，这里取最常见的一种。

这里容易和上一节混：Harness 不也会分派子任务、让几路人马一起干吗？差别在范围和存续时间。Harness 是给“办这一件事”配的装备，事办完，它的活儿就结束了；Super Agent 是跨任务、长期存在的一个角色——它管的不是这一件，而是你手上的一摊子事。

打个比方：Harness 是帮工身上那套装备，Super Agent 是那个替你管着一屋子帮工的人。装备再好，也回答不了“我手上这五件事，谁在管、办到哪了”这个问题——那得有人。

关键差别不是“更聪明”，而是“它替你操心”。

<strong>普通 Agent 是：</strong>你交代一件，它办一件；办完就等你下一句。你得记着它知道什么、不知道什么，还得记着自己上次说到哪了。

<strong>Super Agent 是：</strong>你不用反复交代，也不用替它记事。 它像一位管家，带着一支团队，替你把整摊子事统筹起来。

你能感受到的，主要是三点：

**一直在线，记得你。 上次说孩子对花生过敏，这次订餐厅它自己就避开了。你不用重讲一遍。**

**可以同时办几件事。 订票、比酒店、排行程、查天气，几路人马一起跑，最后汇总给你一个结果。技术上这叫多智能体（Multi-Agent）：不是一个帮工硬扛，而是分成两层——调度者（Router）负责分派任务，执行者（Worker）负责分头去干。**

**会主动提醒你。 “下周三该值机了”“这家酒店明天涨价”，不用你问。**

说白了：一个人跑腿，你得全程盯着；一个管家带团队，你只管拍板。

## 四、三个词放一起看

一句话收束：

**谁在干活——Agent。谁在递工具、定规矩——Harness。谁在替你统筹——Super Agent。**

![图3：三个词的分工](/images/blog/agent-harness-super-agent/fig3-three-words.webp)

普通人判断一个 AI 到底行不行，问三句就够：

它能不能自己把事办完？

办错了会不会自己改？

要不要你一直盯着？

三句都答“是”，才算真的能替你把事办完。否则，它还是那个只会说“祝您旅途愉快”的聊天框。
